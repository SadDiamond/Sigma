# Sigma Game Launcher

## macOS/Linux
Run the game with:

    ./run_sigma.sh

If you get a permission error, run:

    chmod +x run_sigma.sh

## Windows
Run the game with:

    run_sigma.bat

Or open Command Prompt in this folder and run:

    python main.py

---
Requires Python 3. If you have issues, ensure Python is installed and available in your PATH.
